# Bezpečnostní politika

## Nahlášení zranitelnosti

Do veřejného issue nikdy nevkládejte tokeny, přihlašovací údaje ani detailní postup zneužití. Pro bezpečnostní problém použijte soukromé hlášení přes GitHub Security Advisory tohoto repozitáře.

## Automatické kontroly

GitHub Actions provádějí testy, lint, kontrolu známých zranitelností produkčních závislostí, CodeQL analýzu a dependency review pull requestů. Dependabot pravidelně navrhuje aktualizace závislostí.

GitHub Secret Scanning a Push Protection se konfigurují v nastavení repozitáře na GitHubu a nejsou náhradou za bezpečné ukládání tokenů ve VS Code SecretStorage.
